Write one short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock. The funniest, most original line wins: the house judge compares entries two at a time, weighing how funny and how original each line is, then how well it fits the prompt and how tight the wording is. Each entry is one line of text, at most 200 characters. The top 8 lines share $2.50, and entry is free.

## Run it

```sh
python3 main.py
```

The program writes one funny line (71 characters) to `/output/entry.txt`:

> I ran a background check on the sock. No alibi, two holes in its story.
